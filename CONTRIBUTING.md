# Contributing to MediSphere AI

Thank you for your interest in contributing to MediSphere AI!

## Development Workflow

1. **Fork & Branch**: Create a feature branch off `main` following `feature/short-description`.
2. **Code Standards**:
   * **Python**: Strict type hints, `loguru` structured logging, Pydantic v2 validation.
   * **TypeScript**: Strict types, zero `any`, Lucide icons, Tailwind styling.
3. **Testing**: All pull requests must include unit/integration tests and pass `pytest backend/tests`.
4. **Pull Requests**: Open a PR with completed template description and request review.
