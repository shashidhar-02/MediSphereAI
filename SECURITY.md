# Security Policy — MediSphere AI

## Supported Versions

| Version | Supported | Security Updates |
| :--- | :---: | :--- |
| 1.0.x | Yes | Active security patches |
| < 1.0 | No | Deprecated |

---

## Reporting a Vulnerability

MediSphere AI takes healthcare data privacy and platform security seriously.

If you discover a security vulnerability:
1. **DO NOT** create a public GitHub issue.
2. Email private security details directly to `security@medisphere.ai` or submit a private Security Report template.
3. Include clear steps to reproduce, affected component version, and proof of concept payload if applicable.

We aim to respond to security reports within 24 hours and issue patches within 72 hours for critical findings.
